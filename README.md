# Almaty sans frontières / Алматы без границ

Mini-guide culturel bilingue (français, russe) consacré à six lieux d’Almaty :
le monument du Mahatma Gandhi, le monument de Taras Chevtchenko, le monument
de Viktor Tsoï, le buste d’Alexandre Pouchkine, le centre Tselinny et
l’Almaty Museum of Arts. Carte interactive avec itinéraire à pied et
audioguide dans les deux langues.

Двуязычный культурный мини-гид (французский, русский) о шести местах Алматы,
с интерактивной картой, пешим маршрутом и аудиогидом.

Projet scolaire réalisé par Anastasia Telyuk. / Школьный проект, автор — Анастасия Телюк.
